# wildfire-risk-prediction
Wildfire Risk Prediction using Fire Weather Index (FWI), Machine Learning, and Data Analytics.

#Overview
Wildfires pose significant environmental and economic challenges worldwide. This project utilizes weather conditions and Fire Weather Index (FWI) components to analyze and predict wildfire risk levels.

#Objectives
Analyze wildfire-related weather data
Explore Fire Weather Index components
Build predictive machine learning models
Visualize wildfire risk patterns
